# photoframe 仕様

## 目的

NAS 上の写真を Raspberry Pi 4 に接続した FHD ディスプレイでスライドショー表示する、24時間稼働のデジタルフォトフレーム。

## 前提環境

- Raspberry Pi 4 Model B（メモリ 4GB）
- Raspberry Pi OS（Debian 13 trixie ベース）64bit、Desktop 版
- ディスプレイ：1920x1080、横置き
- 画像の置き場所：QNAP NAS の SMB 共有フォルダ（認証あり）。OS 側で CIFS としてマウントし、アプリはマウント先のフォルダをローカルのファイルとして読む

## 機能要件

- F1. 設定で指定したフォルダ（NAS のマウント先）の画像を表示する
- F2. 表示順はシャッフルを基本とする。完全な一巡でなくてもよく、最近表示した画像ほど選ばれにくくする方式でもよい。再起動をまたいで表示履歴は保持しない
- F3. 1920x1080 の横置き画面にフルスクリーンで表示する
- F4. 30秒〜10分程度の間隔で画像を切り替える（設定で変更可能）
- F5. 表示モードは次の2つ。どちらかに固定するか、画像ごとにランダムにするかを設定で選べる
  - fit：画像全体が画面に収まるように拡大縮小し、余白は黒で埋める
  - fill：短い辺を画面に合わせて拡大し、はみ出た部分を切り捨てる
- F6. 切り替え効果は、なし・フェード・横スライド・縦スライド。設定した候補の中から切り替えのたびにランダムに選ぶ。効果の継続時間は 1〜2 秒程度（設定で変更可能）、描画は 20fps 以上
- F7. 電源投入後、自動でスライドショーを開始する
- F8. NAS 側での画像の追加・削除を、1時間〜1日に1回程度の頻度で反映する（間隔は設定で変更可能）
- F9. 設定した時間帯（毎日同じ、例：23:00〜7:00）は HDMI 出力を止めてモニターをスタンバイにする
- F10. RAM 上に容量上限付きの画像キャッシュを持つ。指定フォルダを読めないとき（NAS に接続できない、マウントが外れている、応答がないなど）はキャッシュの画像で表示を続け、キャッシュも空なら黒い画面に小さくエラーを表示する
- 画像上への情報表示（撮影日など）と操作機能は持たない。完全に放置して使う

## 非機能要件

- N1. メモリ・CPU の使用量が少ない
- N2. 24時間連続で動き続ける（メモリ使用量が増え続けない、異常終了時は自動で再起動する）
- N3. OverlayFS を有効にし、microSD への書き込みをほぼなくす
- N4. GitHub で公開する。環境に依存する値はリポジトリ外の設定ファイルに分ける。NAS の認証情報はリポジトリ外のファイルに置き、リポジトリには含めない
- N5. sudo が必要な作業（NAS のマウント設定、OverlayFS の有効化など）は手順書としてまとめ、手動で実施する

## 未確認事項

- NAS 上の画像の傾向（形式、解像度、ファイルサイズ、枚数、フォルダ構成、EXIF の回転情報）。NAS をマウントしてから調べる
